## SPE 10 – MODEL 2

В этом каталоге лежит модель месторождения SPE 10 – MODEL 2, представленная в статье SPE «Tenth SPE comparative solution project: a comparison of upscaling techniques» авторов M. Christie и M. Blunt, SPE, 2001.

Описание модели: [https://www.spe.org/web/csp/datasets/set02.htm](https://www.spe.org/web/csp/datasets/set02.htm).

Мы воспроизводим этот набор данных с учётом того, что исходный расчёт месторождения распространяется по открытой лицензии Open Database License [http://opendatacommons.org/licenses/odbl/1.0/](http://opendatacommons.org/licenses/odbl/1.0/), а отдельные материалы внутри базы данных — по лицензии Database contents License [http://opendatacommons.org/licenses/dbcl/1.0/](http://opendatacommons.org/licenses/dbcl/1.0/).
