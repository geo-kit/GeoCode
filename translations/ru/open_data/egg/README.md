## Модель месторождения Egg

В этом каталоге лежит рассчитанная модель месторождения Egg. Модель описана в статье: Jansen, J. D. et al. (2014), The egg model – a geological ensemble for reservoir simulation. Geosci. Data J., 1: 192–195. https://doi.org/10.1002/gdj3.21.

Перед работой с данными распакуйте файл RESULTS.zip.

Источник набора данных: J. D. Jansen (2013), The Egg Model – data files. Version 1. 4TU.ResearchData. dataset. https://doi.org/10.4121/uuid:916c86cd-3558-4672-829a-105c62985ab2. Условия использования наборов данных 4TU.Centre требуют, чтобы при любой дальнейшей передаче третьими лицами сохранялось это указание на источник. Подробности — в файле [General_terms_of_use.pdf](../../../../open_data/egg/General_terms_of_use.pdf).
