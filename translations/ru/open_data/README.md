## Общедоступные наборы данных

В этом каталоге собраны модели месторождений, на которых удобно осваивать набор средств `GeoCode`:
* модель Egg ([источник](https://doi.org/10.1002/gdj3.21)) с рассчитанной динамикой. Перед чтением результатов расчета модели средствами `GeoCode` распакуйте архив `RESULTS.zip`
* SPE 10 — MODEL 2 ([источник](https://github.com/OPM/opm-data/tree/master/spe10model2))

Подробности и условия использования моделей приведены в описании внутри каталога каждой модели.

Другие модели можно взять в хранилище `opm-data`: https://github.com/OPM/opm-data.
